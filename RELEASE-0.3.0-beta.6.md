# BURNRATE 0.3.0-beta.6

This maintenance beta adds published-rate coverage for model identifiers found
in recent local usage:

- Cursor Grok 4.6 standard and Fast effort variants, Composer 2.5 Fast, Muse
  Spark 1.3, GPT-5.6 Luna and Sol variants, and Claude Opus 5 thinking.
- OpenCode sessions recorded with OpenAI GPT-6 Astra, xAI Grok 4.6, or Cursor
  Muse Spark and GPT-5.6 Luna providers.
- ZCode GLM-5.3 Coding Plan usage.

These values are derived published-rate equivalents and do not convert Cursor
included capacity or Z.AI credits into an invoice. Existing complete historical
events that now resolve can be promoted from the pricing gap to measured usage;
incomplete telemetry stays unpriced.

DeepSeek Flash and OpenRouter DeepSeek V4.1 Flash remain unavailable in this
release because their providers publish time-of-day price schedules that the
current dated card format cannot represent safely. BURNRATE continues to show
those records as unpriced rather than inventing a blended or off-peak rate.
